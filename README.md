# Employee Salary Form

A simple web-based form to collect employee details and calculate total salary based on allowances.

---

## 📋 Features
- Input fields for:
  - First Name
  - Last Name
  - Basic Salary
  - HRA (House Rent Allowance)
  - TA (Travel Allowance)
  - DA (Dearness Allowance)
  - Designation
- Buttons:
  - **Submit**: Save employee details
  - **Calculate Sum**: Compute total salary
